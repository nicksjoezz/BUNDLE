**Technicals:**
- **Backend:** Python/Flask. Uses `asyncio` for non-blocking RPC calls and `httpx` for API interactions.
- **Frontend:** React + Vite + Tailwind. Animations handled by Framer Motion.
- **Blockchain:** Integrated with Helius RPC and Jito Block Engine for high-priority landing.

**Core Functionality:**
1. **The Token Forge:** You can upload an image, add Telegram/Twitter/Web links, and launch a token with a mass-buy bundle across multiple sub-wallets in one click.
2. **The Wallet Array:** It manages a main wallet and up to 20 sub-wallets. Includes a **Vanity Address Engine** that mines custom addresses in a background thread while you work on other things.
3. **Sniper Farmer Mode:** Allows you to monitor multiple tokens simultaneously and trigger creator sells based on USD liquidity thresholds.
4. **Strategic Exits:** Tools for dumping percentages across all wallets, delayed selling to minimize price impact, or aggregating all tokens to the dev wallet before a final liquidation.

**Why I built this:**
The Solana ecosystem moves fast. I wanted a tool that centralized wallet management, funding, launching, and selling into one visual interface that actually feels like you're in a terminal.
